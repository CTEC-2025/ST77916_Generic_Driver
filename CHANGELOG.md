# Changelog

## v0.4.0

- Added RGB565 colour constants and an `ST77916_rgb565` helper.
- Added Arduino and STM32 HAL port adapter layers.
- Added quick-start and porting documentation.
- Added GitHub Actions CI for the core driver.
- Added horizontal, vertical, and diagonal line drawing helpers.
- Added rectangle outline drawing.
- Added circle outline and filled-circle drawing helpers.
- Added screen fill, single-pixel, and clipped rectangle drawing helpers.
- Added example adapters for Arduino, PIC, AVR, ATtiny, SAMD, and STM32.
- Added public API reference documentation.
- Updated README with examples folder information.

## v0.2.0

- Added version macros.
- Added display address-window selection.
- Added raw RGB565 pixel writes.
- Added single-colour fill helper.
- Added rotation command support.
- Updated README usage examples for drawing.

## v0.1.0

- Added basic reset and initialization flow.
- Added platform-neutral bus callback interface.
- Added GitHub support files and MIT license.
